### Hello,
I'm a software engineer based in Seoul, working on agentic systems. I build tools for coding agents and explore how they fit into everyday software development. Lately, I've been exploring how agents coordinate and how we can make their work visible. That curiosity also shows up in projects around local knowledge search and voice interfaces. I like having room to follow an idea through the details and let the project change as I learn more about it.

**Projects :**<br>
[IRI](https://www.jbaehova.com/detail/iri): A Korean voice conversation sandbox for children.<br>
[EDEN API](https://www.jbaehova.com/detail/eden-api): Public APIs and a dashboard for Korean tourism data.<br>
[Fruit Truck](https://github.com/jbaehova/fruit-truck): A macOS studio for AI image and video generation.<br>
[Oh My Neuro](https://github.com/jbaehova/oh-my-neuro): A local RAG knowledge assistant.<br>
[Argus](https://github.com/peerproblem/argus): Visual observability for comparing agent performance and tracing execution.
